# АНКОР ПЛЮС — anchorplus.ru

Статический сайт без сборки: файлы репозитория заливаются на хостинг как есть.
HTML намеренно без комментариев (исходник виден любому на проде) — вся
документация проекта живёт в этом файле.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | лендинг (русский текст — в разметке, EN подменяется скриптом) |
| `privacy.html` | политика конфиденциальности (RU и EN блоками, переключение по `html[lang]`) |
| `send.php` | приём формы и отправка на почту через `mail()` на Beget; получатель — `RECIPIENT`, отправитель `FROM` — ящик на домене сайта (иначе письма уходят в спам) |
| `css/style.css` | все стили |
| `js/i18n.js` | движок RU/EN + словарь EN; выбор языка — в `localStorage` (`ankor-lang`) |
| `js/main.js` | меню, карусель, появление блоков, форма |
| `js/cookie.js` | плашка cookie |
| `robots.txt`, `sitemap.xml`, `.htaccess` | SEO: индексация, карта сайта, 301-склейка зеркал на `https://anchorplus.ru/` |
| `tools/make-map.mjs` | генератор SVG-карты географии |

## Деплой (Beget)

Панель Beget → Файловый менеджер → `anchorplus.ru/public_html` → залить изменённые
файлы поверх. На сервер НЕ нужны: `README.md`, `.git`, `.claude`, `.idea`, `tools`.

Кэш и gzip настроены на стороне Beget (не в `.htaccess`): CSS/JS/SVG — 7 дней,
картинки — 30. Поэтому **при изменении css/js увеличить `?v=` у этого файла
в обеих страницах** (`index.html` и `privacy.html`) — иначе посетители неделю
будут видеть старую версию.

## Языки (i18n)

Новая строка на сайте: атрибут `data-i18n="ключ"` в HTML (русский текст прямо
в разметке) + перевод с тем же ключом в словаре `EN` в `js/i18n.js`.
Для атрибутов — `data-i18n-alt`, `data-i18n-placeholder`, `data-i18n-aria-label` и т.п.

## Яндекс.Метрика

Счётчик **111092687** (аккаунт заказчика), код стоит на обеих страницах.
При успешной отправке формы `main.js` шлёт цель `zayavka` — в интерфейсе Метрики
должна существовать цель типа «JavaScript-событие» с идентификатором `zayavka`,
иначе события не считаются.

## Подтверждение прав в поисковиках

Когда придёт код из Яндекс.Вебмастера или Google Search Console — добавить
в `<head>` `index.html`:

```html
<meta name="yandex-verification" content="КОД">
<meta name="google-site-verification" content="КОД">
```

и залить файл. Ресурс в Search Console заводить как «Префикс в URL»
(`https://anchorplus.ru/`), не «Домен» (тот требует DNS-записи).

## Плашка cookie

`js/cookie.js`: показывается до нажатия «Хорошо», выбор — в `localStorage`
(`ankor-cookie-ok`). В `style.css` обязательно правило
`.cookie-notice[hidden] { display: none }` — без него `display: flex` плашки
перебивает браузерное скрытие по `hidden`.

## Форма заявки

Клиентская валидация в `main.js` (имя, телефон = 10 цифр, согласие),
отправка `fetch` POST на `send.php`, скрытое honeypot-поле `website` против ботов.
Сообщение об успехе показывается только после ответа сервера; серверная
валидация продублирована в `send.php`.
